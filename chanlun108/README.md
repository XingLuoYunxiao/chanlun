### 三处已知的缺口（不是抓取失败）

- **第 34、72、80 课评论极少**（28 / 1 / 13 条）。新浪接口对这三篇返回的
  `data` 是 `博主已关闭评论`——**当年博主就没开评论**，不是没抓到。
- **第 62、93、98、99、100 课**一度每个请求都返回 `A00001`（限流假空），
  加重试后已全部取到（595–1,087 条）。
- **缠中说禅本人的回复只到 2007-08-09**（日期范围 2006-06-07 → 2007-08-09，
  覆盖 62 课）。这是两个独立来源一致的结论，不是漏抓：
  从第 101 课《答疑1》起，他改成**在正文里集中答疑**
  （原文：「这里不定时答疑，各位有问题的，最好集中一下」），
  所以第 62–108 课基本没有评论区回复，那部分问答在**原文正文**里。

### 为什么不能只靠论坛站

论坛自身把回复设了权限墙：每课讨论帖（`tid=390`…`tid=1313`）2 楼起对游客显示
「系统提示：您所在用户组阅读权限不足」；站内另一套「含回复」分课帖
（tid 10985–11129）游客直接是「抱歉，您所在的用户组(铁杆缠迷)无法进行此操作」。

绕路都试过、都无效：手机 UA、`archiver`、`mobile=yes`、镜像 `chanluntan.com`。
最后是靠**新浪原站接口 + 第三方公开存档**把评论补齐的——这也是总量从最初
1,287 条涨到 82,942 条的原因。

要读论坛那部分，需要登录态。把浏览器 Cookie 存成文件后：

```bash
cd chanlun108
python3 tools/crawl_chanshi.py replies --cookie cookie.txt
```

`cookie.txt` 放一行，形如 `Cookie: xxxxxxxx_xxxx_saltkey=...; xxxxxxxx_xxxx_auth=...`
（Chrome：开发者工具 → 网络 → 任一请求 → 请求标头 → 整条 Cookie 复制）。
抓完写 `replies_report.json`，`gated` 不为 0 的课就是还没读到的。

### 正文里的站点外壳已被剥离

论坛把两样东西混在正文单元格里，抓下来就是脏字，已用 `_clean_post_html()` 去掉：

- **游客登录提示的关闭按钮**——`<span class="atips_close">x</span>`，去标签后会在
  正文开头留下一个孤零零的 `x`（108 课全中，是系统性脏字）。
- **文末「相关帖子」导航**——`thread-links` 锚点列表，会把下一课的标题
  （如「教你炒股票2：没有庄家，有的只是赢家和输家！」）接到正文尾巴上。

净减 3,601 字，全部是导航文本。核对方式是拿独立的博客存档比对结尾：
第 27 课收在「严禁抄袭，违者必究」、第 47 课收在「周末腐败快乐。」、
第 54 课收在「功夫是要花工夫的。」——与存档逐字一致。
**注意**：`thread-links` 锚点也出现在正文中间（禅师自己引用的其他文章），
那些属于原文，予以保留；只有**文末连续的一段**会被剥掉。

## 重跑

```bash
python3 tools/crawl_chanshi.py catalog     # 建课号→tid 目录
python3 tools/crawl_chanshi.py articles    # 108 课原文 → 原文/
python3 tools/crawl_chanshi.py sina        # 新浪原站评论 → cache/sina/（慢，可断点续跑）
python3 tools/crawl_chanshi.py comments    # 三源合并 → 回复/
python3 tools/crawl_chanshi.py qa          # 禅师回复 → 问答/ 与合集
python3 tools/crawl_chanshi.py bundle      # 单文件全文
python3 tools/crawl_chanshi.py index       # 索引.md / 索引.csv
python3 tools/crawl_chanshi.py check       # 覆盖度核对
```

脚本每次请求间隔 1 秒、不并发、失败退避重试；缓存命中就不打网络。想重抓先删 `cache/`。
新浪接口会用 `A00001` 假空来限流，脚本对空页做退避重试，并且**连续两页为空**才收尾
（最后一页通常不满 50 条，见到就停）。若只想补某几课：`sina --codes 34,72,80`。

两个切分上的坑记一下：

- 正文里常出现「在"教你炒股票29：转折的力度与级别"中」这类**引用**，
  一开始照着「教你炒股票N：」硬切，把第 43 课切成了 139 字。现在要求
  **行首 + 标题对得上**才算一课起点（`_lesson_sections`），并且原文一律用
  `原文/` 里的分课版本，汇编只提供评论。
- 新浪的注册用户昵称是 `<a href=".../u/<uid>">昵称</a>` 这种 HTML，
  作者名要**去标签**；是不是禅师本人要认 `userid`/`href` 里的
  `1215172700`，不能拿昵称包含「缠师」去猜——站内另有「缠中说禅技术基地」
  这类账号，会误判。

## 怎么读才不容易混

- `原文/` 是**原博客正文**；`回复/` 是该课正文**加上**当年博客下面的全部评论；
  `问答/` 只留**禅师本人的回复**，最干净。
- 评论按「作者 · 时间」分块，加粗的 `**缠中说禅**` 块才是他本人的，其余是读者。
- 存档里的文字都是站点原文，**没有任何改写或解读**；本仓库另外那份
  `缠论108课讲了什么.md` 才是整理稿，两者别混。
