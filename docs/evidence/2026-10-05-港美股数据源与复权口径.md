## 1. 腾讯港股的「复权」三态：两个因子模型都不成立

`smartbox` 那套接口里，港股日线有两个入口：通用 `fqkline`（原始价）与专用
`hkfqkline`（`qfq` / `hfq` / 第三个词都一样）。规格 §5 曾打算用
`adjust.infer_factors(raw, qfq)` 反推因子表落库。**这条被实测否掉了** ——
理由不是"看起来不对"，而是下面这三个数字。

```bash
cd /tmp && /Users/zzz/workspace/.venv-chanlun/bin/python -u -c "
import json, subprocess, datetime as dt
def get(u): return json.loads(subprocess.run(['curl','-s','--max-time','40',u],capture_output=True).stdout.decode())
def walk(mode):
    cursor='2026-10-05'; seen={}
    for i in range(12):
        u=(f'https://ifzq.gtimg.cn/appstock/app/fqkline/get?param=hk00700,day,1990-01-01,{cursor},640,qfq' if mode=='raw'
           else f'https://ifzq.gtimg.cn/appstock/app/hkfqkline/get?param=hk00700,day,,{cursor},640,{mode}')
        node=get(u)['data']['hk00700']; keys=[k for k in node if k.endswith('day')]
        rows=node[keys[0]] if keys else []
        if not rows: break
        for r in rows: seen[r[0]]=float(r[2])
        nxt=(dt.date.fromisoformat(rows[0][0])-dt.timedelta(days=1)).isoformat()
        if nxt<'2004-06-16': break
        cursor=nxt
    return seen
raw=walk('raw'); hfq=walk('hfq'); qfq=walk('qfq')
c=sorted(set(raw)&set(hfq))
print('common bars:', len(c))
diff=[hfq[t]-raw[t] for t in c]; rat=[hfq[t]/raw[t] for t in c]
print('hfq-raw 变化次数:', sum(1 for i in range(1,len(diff)) if abs(diff[i]-diff[i-1])>1e-6), '/', len(c))
print('hfq/raw 变化次数:', sum(1 for i in range(1,len(rat)) if abs(rat[i]-rat[i-1])>1e-9), '/', len(c), '范围 %.6f..%.6f'%(min(rat),max(rat)))
print('qfq<=0:', sum(1 for t in c if qfq.get(t,1)<=0), '/', len(c))
"
```

实测输出（2026-10-05）：

```
common bars: 5499
hfq-raw 变化次数: 3009 / 5499
hfq/raw 变化次数: 5171 / 5499 范围 1.000000..5.812090
qfq<=0: 2193 / 5499
```

**这三行各自杀掉一个假设**：

| 假设 | 若成立应看到 | 实测 | 结论 |
|---|---|---|---|
| `hfq` 是「原始价 + 一个随除权次数走的阶梯」 | `hfq-raw` 只在除权日跳变（几十次） | 变了 **3009 / 5499** 次 | 阶梯模型**不成立** |
| `hfq` 是「原始价 × 一个固定因子」 | `hfq/raw` 恒定 | 变了 **5171 / 5499** 次，跨度 `1.000000..5.812090` | 固定因子模型**不成立** |
| `qfq` 可以直接当价格用 | 收盘价恒为正 | **2193 / 5499** 根 ≤ 0（最小 `-55.111`） | `qfq` **不可用** |

也就是说：腾讯港股能拿到的**唯一自洽价格序列是原始价**。
两个因子模型都被自己的数字否掉了，所以 D-43 决定**不落库任何港股复权因子**，
页面显示原始价并**如实写明**「不复权（源只提供原始价）」。

> **⚠️ 后续更正（2026-10-05，`0.5.0`）**：上面那段探针与那三行读数是**第一版**，
> 按「只增不改」纪律保留原样。后来用 `/tmp/hk_readj.py`（`hk00700`，
> `end` 往回翻页、最多 30 次请求、`FLOOR=2004-01-01`）重测，**数字要按下面引用**：
>
> | 量 | 第一版（上面） | 重测（`/tmp/hk_readj.py`） |
> |---|---|---|
> | `common bars` | 5499 | **5499**（不变） |
> | `hfq` 的 bar 数 | 5498 | **5499** —— 第一版最后一次翻页少收了一根 |
> | `hfq − raw`「变化次数」 | 3009 / 5499 | **3008 / 5499**（**相邻不同的次数**） |
> | `hfq / raw`「变化次数」 | 5171 / 5499 | **5170 / 5499**（**相邻不同的次数**） |
> | `hfq / raw` 范围 | `1.000000..5.812090` | **`1.000000..5.812090`**（逐字节相同） |
> | `qfq` 非正收盘 | 2193 / 5499，最小 `-55.111` | **2193 / 5499，最小 `-55.111`**（不变） |
>
> 两点要说清，否则数字对不上：
>
> 1. **「变化次数」这个词本身有歧义。** 上面那个 `sum(1 for i in range(1,len(x))
>    if abs(x[i]-x[i-1])>tol)` 数的是**相邻不同的次数**（阶梯的级数 − 1），
>    不是「值不同的 bar 数」。同一个 `hfq` vs `raw`，**值不同的 bar 数是
>    5292 / 5499**，而**相邻不同的次数是 3008 / 5499** —— 差了一倍多。
>    以后一律写明是哪一种，不许再写裸的「变化次数」。
> 2. **上面那段探针的 `raw` 支路写的是 `fqkline` + `qfq`。** 通用 `fqkline`
>    根本不认 `adj`（`hkfqkline`+`qfq` 才回 `qfqday`，`fqkline` 一律回 `day`），
>    所以这一支**拿到的是原始价、结论没错**，但命令本身会误导读者以为它取的是前复权。
>    正确的 `raw` 支路是 `fqkline` + 任意 `adj`，键名恒为 `day`。
>
> ①②的**结论不变**：`qfq` 不可用（2193/5499 非正）、阶梯模型与固定因子模型
> 都被否证。`CHANGELOG.md` 的 `0.5.0` 条目里同一个更正也补了一份。

## 2. 港股分钟：不可得（三次探测，三种失败方式）

```bash
for u in \
  'https://ifzq.gtimg.cn/appstock/app/hkfqkline/get?param=hk00700,m30,,,320,qfq' \
  'https://ifzq.gtimg.cn/appstock/app/hkMinute/query?code=hk00700' \
  'https://ifzq.gtimg.cn/appstock/app/fqkline/get?param=hk00700,m30,,,320,qfq' ; do
  echo "### $u"; curl -s --max-time 30 "$u" | head -c 400; echo; done
```

| 入口 | 实测 | 为什么不能用 |
|---|---|---|
| `hkfqkline` `m30` / `m5` | `{"code":1,"msg":"bad params","data":[]}` | 直接拒绝 |
| `fqkline` `m30` | `code=0`，但只有 **1 根**，日期 `2026-10-05`、OHLC 是全天（`420.000/423.000/423.600/416.400`） | 这是**日线被贴上 m30 的标签**，不是 30 分钟线 |
| `hkMinute/query` | `code=0`，当天 152 条 `0930 420.000 …` 的**分时** | 只有当天、无历史、不可翻页；算不出跨日的缠论结构 |

所以 `sources.capabilities` 对港股分钟返回 `supported=False`，`reason` 把
**这三种失败方式**都写出来（`sources.py:280-287`）—— 只写"没有分钟线"会让
排查者去试第二个入口。

## 4. smartbox 零命中哨兵：`v_hint="N";`（11 字节，带分号）

```bash
curl -s --max-time 20 'https://smartbox.gtimg.cn/s3/?q=zzzznope&t=all' | od -c | head -3
```

实测 `v_hint="N";`，**11 字节且带尾随分号**。
`search._decode` 的取法是「第一个 `"` 到最后一个 `"` 之间」，
所以 `N` / `N;` 都要映射成空串（`search.py:103-136`）。
副作用：一段 body 里若拼接了两个 `v_hint="…"` 字面量，只会取到**第一个**；
尾随垃圾被静默忽略。这条切片也意味着 `json.loads` **永远返回 `str`** ——
`_decode` 里的 `isinstance(decoded, str)` 分支**不可达**，代码里注释掉了而不是假造用例。

## 5. 「口径说明」必须分两种，不能统一成一句

`GET /api/bars` 的 `adjust_note`：

| 市场 | 该说的话 | 不能说的话 |
|---|---|---|
| A 股（无除权记录） | 「无除权记录（三态相同，价格即不复权原始价）」 | —— |
| 港股/美股 | 「不复权：港股数据源只提供原始价（复权序列实测不可用），另两态取不到」 | ❌「三态相同」 |

港股/美股那两句里「另两态取不到」是**事实陈述**（本文第 1、2 节），
「三态相同」是**另一个命题**（A 股才有）。混用会让用户以为复权算错了。
后端 `web/api.py::_raw_only_note`（`web/api.py:202-213`）按市场分句；
护栏 `tests/web/test_api_adjust_ma.py::test_hk_stock_says_the_other_two_modes_are_unavailable_not_that_none_exist`
断言港股响应**不含**「三态相同」，且 `600000` 作反向对照。

港股落库的 `amount` **恒为 0.0**：本模块走的控制器是 `fqkline`，它的行只有 7 位、
**没有成交额字段**；有第 8 位的是 `hkfqkline`，而它的复权序列实测不可用（本文 §1）。
这不是占位符，是数据商在这条路径上确实没给（`tencent_source.py:96-104`）。
`amount` 全仓库唯一的消费者是 `web/api.py::_bars_payload`，前端不渲染
（`grep amount web/static/app.js` 零命中），不参与缠论计算；将来若要显示，
**不许用 量×均价 编**，只能另找港股成交额源。
