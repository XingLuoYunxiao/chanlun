# 行业指数大弹窗：开关 / 跨级搜索 / 键盘导航 / 点卡片出图（2026-10-06，D-44 Task 4）

## 0. 一句话

入口从 `<select>` 换成按钮 + `<dialog>` 大弹窗之后，**能不能用**全看交互这一层：
点得开、搜得着、键盘走得动、点一张卡就出图。这里把每一步的**真实浏览器 DOM**
逐字读出来贴在下头 —— 截图只能看布局，**文案必须从 DOM 里读**（Task 2 就吃过这个亏：
左栏按钮上塞进了一个 630 字符的行业名，DOM 一读就露，截图上看不出来）。

## 4. 布局目检（截图只看布局，文案以第 2 节 DOM 为准）

- 弹窗盒子实测 `getBoundingClientRect() = [260, 77, 1340, 837]`（视口 `1600 × 913`）：
  宽 **1080**、高 **760**，水平居中（左 260 = 右 260），垂直居中（上 77 / 下 76）。
- `#ind-search` 与 `#ind-tabs` 的 `top` 实测 `158` / `159` —— 同一行。
- 卡片网格在这个视口下是 **5 列**。这个数不是目测的，两次实测互相印证：
  ① 第 2 节 12b 的方向键步长（`↓` 一次走 5 张：`sw.801203` → `sw.801981`）；
  ② 直接把 124 张卡的 `offsetTop` 打出来 —— 前 5 张 `132`，第 6 张起 `197`
  （`sw.801103 / sw.801203 / sw.801724 / sw.801218 / sw.801204` 是第 0 行，
  `sw.801074` 落在第 1 行第 0 个）。
- 布局目检那张截图（`/tmp/d44-shot.mjs`）另用 `Emulation.setDeviceMetricsOverride`
  把视口钉到 `1440 × 1000`，**只影响那一张图**，探针跑的是上头的真实视口。
- `::backdrop` 的计算值是 `color(srgb 0.0588235 0.0705882 0.0862745 / 0.74)`
  —— 即 `var(--ink)` 的 74%，**不是**旧的字面量 `rgba(9, 11, 14, .74)`。
  这是 Task 4 唯一动 `styles.css` 的一行（旧值是全文件唯一一处裸颜色字面量，
  `grep -c 'rgba(' src/chanlun/web/static/styles.css` 现在为 0）。
- 左栏入口按钮上只有「选一个行业…」六个字，没有 Task 2 那种超长行业名。
- **入库的两张截图**（2026-10-06 收尾补，驱动 `/tmp/d44-final-shot.mjs`，
  **视口就是真实视口 `1600 × 913`**，没有用 `setDeviceMetricsOverride`）：
  - `docs/evidence/2026-10-06-行业弹窗-布局.png` —— 一级行业 31 张卡，
    `sw.801120` 一张亮并带「当前」角标，页脚
    「本地已有 1 / 155 个板块的日线。…」；弹窗盒子实测 **1080 × 760**。
  - `docs/evidence/2026-10-06-行业弹窗-搜索分组.png` —— 搜「银行」：tab 条实测
    `display: none`，分组标题实测 `["一级行业（1）", "二级行业（2）"]`，
    3 张卡 `sw.801780 / sw.801782 / sw.801783`（一 / 二级各按序）。

## 5. 没测到 / 未确认

- **只测了一个视口（1600×913）**：窄屏（弹窗固定 1080px 宽，会不会溢出）没测；
  手机宽度没测。**列数是跟着视口变的**（`industryGridColumns` 靠 `offsetTop` 现算，
  所以方向键步长不会错），但别的宽度下是几列，没测。
- 中文是 `value = …; dispatchEvent(new Event("input"))` 灌进去的，**不是真实输入法**
  的组合过程 —— `compositionstart/compositionend` 这条路没走。
- **只测了方向键**，`Tab` / `Shift+Tab` 在弹窗内的焦点循环（焦点陷阱）没测。
- 无头 Chrome 的虚拟时间对 `requestAnimationFrame` 的影响，Task 3 已单独记录，
  这次没重复测。

## 6. 附录 A：探针全文（`/tmp/d44-task4-probe.mjs`）

```js
// D-44 Task 4 真实浏览器验收探针（2026-10-06）
// 跑法：headless Chrome 起在 9222，看盘页在 8888，然后 node /tmp/d44-task4-probe.mjs
// 全部结论都从 DOM / echarts 实例里逐字读出，不看截图。
const PORT = 9222;
const BASE = "http://127.0.0.1:8888";
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
const list = await (await fetch(`http://127.0.0.1:${PORT}/json`)).json();
const page = list.find((t) => t.type === "page" && t.webSocketDebuggerUrl);
if (!page) { console.log("NO PAGE TARGET"); process.exit(2); }
const ws = new WebSocket(page.webSocketDebuggerUrl);
await new Promise((res, rej) => { ws.onopen = res; ws.onerror = rej; });
let id = 0; const pend = new Map();
ws.onmessage = (e) => { const m = JSON.parse(e.data); if (m.id && pend.has(m.id)) { const { res, rej } = pend.get(m.id); pend.delete(m.id); m.error ? rej(new Error(JSON.stringify(m.error))) : res(m.result); } };
const send = (m, p = {}) => new Promise((res, rej) => { const i = ++id; pend.set(i, { res, rej }); ws.send(JSON.stringify({ id: i, method: m, params: p })); });
const raw = async (expr) => (await send("Runtime.evaluate", { expression: expr, returnByValue: true })).result.value;
const show = (label, v) => console.log(`${label} :: ${typeof v === "string" ? v : JSON.stringify(v)}`);
const key = async (k, code, vk) => {
  await send("Input.dispatchKeyEvent", { type: "rawKeyDown", key: k, code, windowsVirtualKeyCode: vk, nativeVirtualKeyCode: vk });
  await send("Input.dispatchKeyEvent", { type: "keyUp", key: k, code, windowsVirtualKeyCode: vk, nativeVirtualKeyCode: vk });
};

await send("Page.enable"); await send("Runtime.enable"); await send("Network.enable");
await send("Network.setCacheDisabled", { cacheDisabled: true });
await send("Page.navigate", { url: `${BASE}/?code=600000&period=day&_=${Date.now()}` });

// 等就绪：tab 铺出来 + 印章不是「尚未加载」
let ready = false;
for (let i = 0; i < 40; i++) {
  await sleep(1000);
  const ok = await raw(`(()=>{const t=document.querySelectorAll('.ind-tab').length;const s=(document.querySelector('#stamp')||{}).textContent||'';return t>0 && !/尚未加载/.test(s);})()`);
  if (ok) { ready = true; break; }
}
show("00 ready", ready);
if (!ready) { console.log("NOT READY"); ws.close(); process.exit(2); }

// 01 打开前的入口文案
show("01 button-text-before-any-pick", await raw(`document.querySelector('#industry-name').textContent`));

// 02 点 #industry → 弹窗 open + 焦点
await raw(`document.querySelector('#industry').click()`);
await sleep(400);
show("02 after-open", await raw(`JSON.stringify({open:document.querySelector('#industry-modal').open,active:document.activeElement.id})`));

// 03 tab 文案
show("03 tab-texts", await raw(`JSON.stringify([...document.querySelectorAll('#ind-tabs .ind-tab')].map(b=>b.textContent))`));

// 04 点「二级行业」→ 卡片数
await raw(`[...document.querySelectorAll('#ind-tabs .ind-tab')].find(b=>b.dataset.level==='2').click()`);
await sleep(300);
show("04 level2-card-count", await raw(`JSON.stringify({cards:document.querySelectorAll('#ind-grid .ind-card').length,selected:[...document.querySelectorAll('#ind-tabs .ind-tab')].filter(b=>b.getAttribute('aria-selected')==='true').map(b=>b.textContent)})`));

// 05 搜「银行」
const search = (t) => raw(`(()=>{const b=document.querySelector('#ind-search');b.value=${JSON.stringify(t)};b.dispatchEvent(new Event('input',{bubbles:true}));return b.value;})()`);
await search("银行"); await sleep(300);
show("05 search-银行", await raw(`JSON.stringify({cards:document.querySelectorAll('#ind-grid .ind-card').length,groups:[...document.querySelectorAll('#ind-grid .ind-group')].map(p=>p.textContent),names:[...document.querySelectorAll('#ind-grid .ind-card-name')].map(s=>s.textContent),tabsHidden:document.querySelector('#ind-tabs').hidden})`));

// 06 搜「801120」
await search("801120"); await sleep(300);
show("06 search-801120", await raw(`JSON.stringify({cards:document.querySelectorAll('#ind-grid .ind-card').length,name:(document.querySelector('#ind-grid .ind-card-name')||{}).textContent||null})`));

// 07 搜「食品」
await search("食品"); await sleep(300);
show("07 search-食品", await raw(`JSON.stringify({cards:document.querySelectorAll('#ind-grid .ind-card').length,groups:[...document.querySelectorAll('#ind-grid .ind-group')].map(p=>p.textContent)})`));

// 08 清空 → 回到二级 124 张
await search(""); await sleep(300);
show("08 cleared", await raw(`JSON.stringify({cards:document.querySelectorAll('#ind-grid .ind-card').length,tabsHidden:document.querySelector('#ind-tabs').hidden,selected:[...document.querySelectorAll('#ind-tabs .ind-tab')].filter(b=>b.getAttribute('aria-selected')==='true').map(b=>b.textContent)})`));

// 09 切回一级 tab → 31 张；local 标记（唯一 local 的 sw.801120 是一级行业）
await raw(`[...document.querySelectorAll('#ind-tabs .ind-tab')].find(b=>b.dataset.level==='1').click()`);
await sleep(300);
show("09a level1-card-count", await raw(`JSON.stringify({cards:document.querySelectorAll('#ind-grid .ind-card').length,selected:[...document.querySelectorAll('#ind-tabs .ind-tab')].filter(b=>b.getAttribute('aria-selected')==='true').map(b=>b.textContent)})`));
show("09b local-flags", await raw(`JSON.stringify({local:[...document.querySelectorAll('#ind-grid .ind-card')].filter(c=>c.dataset.local==='1').map(c=>c.dataset.code),othersAllZero:[...document.querySelectorAll('#ind-grid .ind-card')].filter(c=>c.dataset.code!=='sw.801120').every(c=>c.dataset.local==='0')})`));

// 10 点 sw.801120 那张卡
await raw(`document.querySelector('#ind-grid .ind-card[data-code="sw.801120"]').click()`);
await sleep(7000);
show("10 after-pick", await raw(`JSON.stringify({open:document.querySelector('#industry-modal').open,btnText:document.querySelector('#industry-name').textContent,codeInput:document.querySelector('#code').value,stamp:(document.querySelector('#stamp')||{}).textContent||'',bars:(()=>{const c=echarts.getInstanceByDom(document.querySelector('#chart'));if(!c)return null;const s=(c.getOption().series||[]).find(x=>x.type==='candlestick');return s?(s.data||[]).length:null;})()})`));

// 11 关闭后焦点回到入口按钮
show("11 focus-after-close", await raw(`document.activeElement.id`));

// 12 重新打开 + 方向键导航（roving tabindex）
await raw(`document.querySelector('#industry').click()`); await sleep(400);
show("12a reopen", await raw(`JSON.stringify({open:document.querySelector('#industry-modal').open,active:document.activeElement.id})`));
// 切到二级列表：当前票（一级的 sw.801120）不在里面，roving tabindex 落在第一张卡上，
// 四个方向都能走出「移动」而不是在边界上夹住。
await raw(`[...document.querySelectorAll('#ind-tabs .ind-tab')].find(b=>b.dataset.level==='2').click()`); await sleep(300);
await raw(`document.querySelector('#ind-grid .ind-card[tabindex="0"]').focus()`);
const readNav = `JSON.stringify({focus:document.activeElement.dataset.code,focusIsCard:document.activeElement.classList.contains('ind-card'),zero:[...document.querySelectorAll('#ind-grid .ind-card')].filter(c=>c.tabIndex===0).length})`;
const nav = [];
nav.push(await raw(readNav));
for (const [k, code, vk] of [["ArrowRight", "ArrowRight", 39], ["ArrowDown", "ArrowDown", 40], ["ArrowLeft", "ArrowLeft", 37], ["ArrowUp", "ArrowUp", 38]]) {
  await key(k, code, vk); await sleep(150);
  nav.push(await raw(readNav));
}
show("12b arrow-nav", nav);

// 13 Esc 关闭
await key("Escape", "Escape", 27); await sleep(400);
show("13 after-esc", await raw(`JSON.stringify({open:document.querySelector('#industry-modal').open,active:document.activeElement.id})`));

// 14 setCode 同步按钮文案：顶栏提交 600000
await raw(`(()=>{document.querySelector('#code').value='600000';document.querySelector('#query .go').click();})()`);
await sleep(6000);
show("14 after-setCode-600000", await raw(`JSON.stringify({code:document.querySelector('#code').value,btnText:document.querySelector('#industry-name').textContent,hasPick:document.querySelector('#industry').classList.contains('has-pick')})`));

ws.close();
```
