# 行业弹窗：后端比页面旧时，页脚不许报一个算不出的计数（2026-10-06，D-44 终审补丁）

## 0. 一句话

`/api/industries` 的 item 上多回一个 `local` 之后，多出**第三种静默故障**：
进程**认识**这条路由、却**不认识** `local`（路由比字段老）。这时状态码仍是 `200`，
`res.ok` 拦不住，`it.local === true` 恒为假 —— 155 张卡全暗，页脚把 `have = 0`
印成「本地已有 0 / N 个板块的日线」。**那是一句错话**：真相是**这个进程不知道**，
而「本机真没有板块日线」与「后端比页面旧」长得一模一样。

这里用真实浏览器把**两种情况**的 DOM 逐字读出来对照：修好了没有，看文案。

三条要点，都是逐字从 DOM 里读的：

1. 页脚**改口**了，而且**明确否认**「本机没有数据」——「这不代表本机真的没有板块日线」。
2. 页脚**不再出现**「本地已有 …」这个算不出来的计数（`!(foot).includes("本地已有")` 通过）。
3. **只有页脚坏了**：左栏那句核对日期（`#industry-note`）照样显示、`hidden === false`，

   这正说明这个故障**只**污染「依赖 `local` 的那一处」，不是整页塌掉。

## 5. 这次踩到的坑（如实记）

探针**第一版把期望写错了**：判据 6 / 10 要求 `cards === 155`，实测是 `31`，
于是报了 2 条 FAIL。**错在探针、不在产品** —— 网格按当前级别渲染（一级 31 张），
页脚才数全部 155 项。把期望改成 31 之后 `12 / 12 PASS`。
记在这里是因为「数字对不上先怀疑产品」是个很贵的习惯。

静态侧另有一组护栏（`tests/web/test_frontend_industry.py`，四条断言都做过**变异测试**：
把对应代码改坏，它们会红），见 `ARCHITECTURE.md` 的 D-44 第 9 项与 `CHANGELOG.md`
的 `[Unreleased]`。这里验的是**浏览器里真正读到的那句话**，静态护栏替代不了。

## 6. 补记（2026-10-06 晚）：数据前提变了，探针跟着改

同一天晚上用户要求把一级 / 二级**全部 155 个板块**的日线同步下来，本机从
「只有 `sw.801120` 亮」变成 **155 / 155 全亮**（见
`docs/evidence/2026-10-06-行业板块全量同步.md`）。于是这份文档的 §1 数据前提
和 §3 的 `1 / 155`、`lit: 1` 都不再是当前状态 —— **§2 / §3 保留原样，因为那是
当时的实测记录**，改了就成了伪造历史。

探针本身必须跟着改，否则一跑就误报。改动有两处：

1. **期望值不再写死**，改成从 `GET /api/industries` 现算（`EXP` / `TABS`）。
   这两条判据要测的是「页脚 / 亮灯报的是不是**接口说的那个真值**」，
   而真值随本机数据状态变 —— 写死只会让它随数据漂移而说谎。
2. **补了场景 C**：把一个 `local: true` 的板块改成 `false`。

### 为什么非补场景 C 不可

只做第 1 步会引入一条**恒真**判据。全部同步完之后 `have` 恰好等于 `total`
（155 == 155），于是把 `const have = industryRows.filter((r) => r.local).length`
改成 `industryRows.length`（页脚改报总数），印出来**还是同一句话**
「本地已有 155 / 155」—— 场景 B 那条判据分辨不出来。原来 `1 / 155` 时它能分辨
（这正是它当初能抓住「`have` 恒报总数」这个变异的原因）。

场景 C 让页面自己算出 `have ≠ total`（少 1），判据就不再依赖数据状态。

**变异实测**（把 `have` 改成 `industryRows.length`）：

```
FAIL  C 页脚报真计数（比总数少 1）
PASS  B 页脚报真计数          ← 同一个变异，B 照样绿：上面说的退化，实测如此
15 / 16 PASS      退出码 1
```

还原后 `16 / 16 PASS`、退出码 `0`（用 `cp` 备份还原，**没有** `git checkout --`）。

### 判据：12 → 16

| 场景 | 补丁 | 条数 | 期望 |
| --- | --- | --- | --- |
| 前置 | — | 1 | 本机至少一个板块有日线（否则 C 退化成 B） |
| A | 摘掉 `local` | 8 | 同 §4 的 1–8，**未改**（`lit === 0` 与数据状态无关） |
| B | 不打补丁 | 4 | 页脚报真计数、亮卡数 == 接口说 `local` 的一级只数（数字现算） |
| C | 一个 `local: true` → `false` | 3 | 页脚报真计数（比总数少 1）、亮卡数少 1、不说自己是旧后端 |

`cards` 的期望也从写死的 `31` 改成 `EXP.l1`（接口报的一级只数）——
网格渲染的是**当前级别**的卡，不是全部 155 项。
